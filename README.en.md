# RGW · Recognize Genuine Websites

**Never land on a fake official site again.**

RGW (认官网) is a curated directory of official websites — every single one manually opened and verified by a human. No download portals, no mirror sites, no phishing.

🌐 Live: https://renguanwang.com

[中文版](./README.zh-CN.md)

## Stats

- **8320** verified official websites
- **180** countries / regions
- **15** categories (Essentials, AI Tools, Productivity, Dev Tools…)
- **24** UI languages (auto-switches with selected country)

## Philosophy

- Only manually verified official sites. No download sites, cracks, mirrors, or phishing.
- Every site shows its real domain, a one-line description, and pricing.
- Sponsored placements are clearly labeled and never affect organic ranking.

## Run locally

Pure static site. Open `index.html` directly, or serve over HTTP:

```bash
cd renguanwang
python3 -m http.server 8000
# open http://localhost:8000
```
